Watch Closure GC

A reactive watch registered by method name via $c().onExpressionValueChange("m().count", this, "onCountChange"). The name resolves to a prototype method, so the watch survives a forced GC. (Inline closures are no longer accepted by the API, which removes the prior closure-GC footgun by design.)

count: "{{m().count}}"
